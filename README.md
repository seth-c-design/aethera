# Aethera

A cinematic, dark-mode photography portfolio built with React + Vite + Tailwind CSS + Three.js.

## Features

- Custom video background with smooth fade-in/fade-out seamless looping
- Layered mouse-driven parallax
- 3D photo viewer powered by Three.js + React Three Fiber
- Elegant dark aesthetic using Instrument Serif + Inter
- Fully responsive

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Three.js + @react-three/fiber + drei
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deployment (GitHub Pages)

This project is configured with `base: '/aethera/'`.

For GitHub Pages:
1. Push to GitHub
2. Go to Settings → Pages
3. Set source to "GitHub Actions"
4. Use the included workflow or deploy the `dist` folder
